Privacy Policy

Last updated: October 19, 2026

This policy covers Copium Uploader, the publishing tool of the Copium Videos YouTube channel, and this website.

Who uses Copium Uploader

Copium Uploader is used only by the owner of the Copium Videos channel, to manage that one channel. It is not offered to the public, and it never signs in to anyone else's Google account.

Google data it accesses

With the channel owner's permission, Copium Uploader requests these Google OAuth scopes:

  • youtube.upload: to upload the channel's videos.
  • youtube.readonly: to read the status and public statistics (views, likes, comments) of the channel's own videos.
  • yt-analytics.readonly: to read the channel's own YouTube Analytics reports, such as average view duration.

It cannot delete or edit videos, read private messages, or access any other Google service.

How the data is used

Video statistics are used only to learn which of the channel's videos work best and to improve future videos. They are not sold, shared with third parties, or used for advertising.

Where the data is stored

Everything stays on the channel owner's computer. The Google sign-in token is encrypted with Windows data protection so only the owner's Windows account can read it. Video statistics are kept in a local database. Nothing is sent to any server other than Google's own APIs.

Copium Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Viewers and this website

Copium Uploader does not collect any data about the channel's viewers beyond the aggregated numbers YouTube Analytics reports. This website uses no cookies, analytics or trackers. It is hosted on GitHub Pages, which may keep standard server logs; see GitHub's privacy statement.

Watching the channel on YouTube is covered by Google's Privacy Policy and the YouTube Terms of Service.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file and database removes all stored data.
